# **Activity 4: Multi-Page Student Profile**





**Name: Peterson C. Pepito**

**Project: Pepito_StudentProfile with multipage nav**

**Project Description**
This is my updated multipage student profile mobile application developed using Apache Cordova. 
This student profile contains my homepage, an about me, my skills or current tech stack, personal projects, and contact page. 
     

**Application Pages**
   Explain the purpose of each page:

**Profile**
My profile page is basically my homepage that tells a basic overview about me. 

**About**
My about page tells a detailed personal information, my career goals, educational background, hobbies, etc. 


**Skills**
My skills page tells my current technical stack and technical knowledge of what I have experienced using so far. 


**Projects**
My projects page contains my personal and academic projects such as a college enrollment database, rental booking, personal digital portfolio, and the tech I used to create these projects. 


**Contact**
My contact page contains my GitHub profile, email address, and my personal address.

**Navigation** 
In navigating through my application  all the pages are linked through HTML href. 


**Responsive Design**

**Desktop**
The interface transitions to a three-column grid (min-width: 1024px), and the navigation header reorganizes into a horizontal bar with right-aligned links to prevent stretching.

**Tablet**
The layout expands to a two-column grid (min-width: 768px) for the Skills and Projects sections.

**Mobile**
Stacked the elements vertically in a single-column layout. A specific landscape orientation media query triggers on shorter screens (max-height: 600px), shrinking the header and arranging the profile picture and text horizontally to maximize vertical reading space.

UI/UX Principles Applied

Accessibility - Semantic HTML tags are used alongside high-contrast text and descriptive alt tags on images to ensure the content remains readable, organized, and understandable.

Visual Hierarchy - Distinct font sizing, bold weights, and a primary/secondary color palette are used to cleanly separate section headers from supporting text. Active pages in the navigation menu are highlighted with a distinct background color.

Simplicity & Consistency - A unified color scheme, typography (-apple-system), and button style are maintained across all five HTML pages to ensure the app feels like a cohesive system rather than disconnected pages.

Touch Interaction - Navigation links are styled as prominent buttons with a minimum width (min-width: 90px) and sufficient padding to prevent accidental taps on mobile touchscreens. The links wrap neatly using flex-wrap to prevent overflowing.

How to Run
   Provide the steps necessary to build and run the Cordova application.

For other ppl to run my mobile application they can follow these steps:

- clone my GitHub repo into their local machine then navigate to the root directory of my project
- run the command "Cordova prepare android" to sync my updated html and css files from the www/ folder to the android platform directory, then use AVD for tablet and mobile. 
- run the command Cordova emulate android for the APK and deploy my app to any AVD emulators.
